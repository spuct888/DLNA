# 2026-06-12

## DLNA Toast 叠加问题修复

修复了 DLNA 投屏应用 MainActivity.java 中的 Toast 叠加显示问题。

**问题**：连续快速操作遥控器（快进、快退、旋转、缩放等）时，多个 Toast 消息排队依次显示，导致提示需要等很长时间才能消失。

**原因**：Android 的 Toast 队列机制会将每次 `Toast.makeText().show()` 排队显示，前一条要等 `LENGTH_SHORT`（约4秒）后才显示下一条。

**修复**：使用 `lastToast.cancel()` 在每次显示新 Toast 前取消之前的 Toast，确保只显示最新的提示。新增 `lastToast` 字段缓存上一个 Toast 实例。
